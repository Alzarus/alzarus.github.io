Tô De Olho

Web · In Production · IFBA Capstone

Web platform for legislative transparency and civic oversight dedicated to continuous monitoring of the Brazilian Federal Senate, developed as a Capstone Project at the Federal Institute of Bahia (IFBA). The system aggregates official open data on legislative bills, roll-call voting, committee engagement, parliamentary amendments, and quota expenses (CEAPS), computing a weighted parliamentary effectiveness and fiscal transparency index.

  • Concurrent ingestion pipeline combining historical backfill routines with live synchronization against the Senate Open Data API and Transparency Portal.
  • High-performance Go backend (Gin and GORM) with Redis caching and relational persistence in PostgreSQL 15.
  • Decoupled Next.js 15 frontend (App Router), TypeScript, Tailwind CSS, Shadcn/UI, and analytical visualizations with Recharts.
  • Docker Compose infrastructure with Cloudflare Zero Trust secure tunneling and continuous deployment.
Go (Gin) PostgreSQL 15 Redis Next.js 15 TypeScript Tailwind CSS Docker Compose Cloudflare Zero Trust
Access todeolho.org Capstone Research Paper (IFBA)

Quem Votar

Web & Cross-Platform · In Production

Cross-platform civic application integrated into the Tô De Olho ecosystem, designed to provide public, transparent, and accessible insights into candidate profiles, asset declarations, and official electoral data from Brazil's Superior Electoral Court (TSE). The platform provides parameterized searches by office, state, and electoral cycle, advanced filters by registration status, party, and asset tiers, detailed breakdowns of declared assets and government plans, alongside a side-by-side comparison matrix of up to four candidates simultaneously without partisan bias.

  • Reactive web interface compiled with Flutter Web utilizing BLoC state management and local persistence/caching via Drift (SQLite).
  • Autonomous Node.js data worker with dedicated SQLite instance, executing scheduled 24-hour ingestion cycles across 109 electoral datasets from TSE DivulgaCandContas.
  • Architectural decoupling ensuring third-party TSE infrastructure stays outside the critical path of user requests.
  • Nginx web server on dedicated virtual machine (Contabo) with secure routing and Cloudflare edge caching.
Flutter Web Dart BLoC Drift (SQLite) Node.js DivulgaCandContas TSE Nginx Cloudflare
Access todeolho.org/quemvotar

NeuroAnálises

Web & Telemetry · In Production

Autonomous platform for continuous telemetry, high-performance persistence, and time-series analysis of online gaming platforms (Double modality). Built for analytical auditing and probabilistic modeling, the application monitors real-time events, computing empirical frequency distributions, consecutive streaks, statistical skewness, and intervals between rare outcomes, enabling formal verification against theoretical multinomial expectations.

  • High-cadence ingestion engine (7-second cycles) with exponential backoff, rate-limit resilience, and timestamp jitter compensation.
  • Idempotent historical backfill with strict deduplication based on official round identifiers.
  • TypeScript backend using Fastify and Better-SQLite3 in WAL mode, serving aggregated queries in under 50ms with less than 30 MB memory consumption in production.
  • Real-time analytical dashboard with auto-synchronization (3s), dynamic time windows (1 hour to complete history), and batch data export in JSON and CSV formats.
TypeScript Node.js Fastify Better-SQLite3 (WAL) Time Series Telemetry Docker Linux VPS
Access neurofluxis.com/neuroanalises
